# 用户与权限使用手册

涵盖：客户端用户、管理员、权限管理、在线管理。

---

## 1. 客户端用户管理

### 入口

- 菜单：`用户管理 → 客户端管理`

### 你能做什么

- 查看 C 端用户列表与基础信息
- 通过搜索/筛选快速定位用户（以页面实际控件为准）

---

## 2. 管理员列表（后台用户）

### 入口

- 菜单：`用户管理 → 后台管理 → 用户列表`

### 顶部操作

- 支持筛选：关键字、状态、身份（以页面控件为准）
- `重置`：清空筛选并恢复列表

### 常见按钮与预期结果

- `新建管理员`
  - 打开创建弹窗
  - 填写账号、密码、姓名、邮箱、身份、负责类目等
  - **预期结果**：提交成功后列表出现新管理员

- `编辑`
  - 打开编辑弹窗，修改姓名/昵称/邮箱/身份/负责类目
  - **预期结果**：保存后列表对应字段更新

- `重置密码`
  - 打开弹窗，可手动输入或随机生成
  - **预期结果**：确认后提示成功，新密码立即生效

- `禁用`
  - 二次确认后禁用该管理员
  - **预期结果**：该管理员无法继续登录；页面提示中说明“禁用后不支持再启用”（以页面提示为准）

- `删除`
  - 二次确认后删除
  - **预期结果**：管理员从列表移除（不可恢复）

---

## 3. 权限管理

### 入口

- 菜单：`用户管理 → 后台管理 → 权限管理`

### 典型使用方式

- 选择一个“身份/角色”
- 查看它拥有的菜单/权限项
- 保存后生效

### 预期结果

- 不同身份登录后台后，能看到的菜单与可操作范围发生变化

---

## 4. 在线管理

### 入口

- 菜单：`用户管理 → 后台管理 → 在线管理`

### 常见操作

- 查看在线管理员
- 强制下线

### 预期结果

- 被强制下线的账号需要重新登录才能继续操作
