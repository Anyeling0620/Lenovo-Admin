# 常见问题与排错（FAQ）

本 FAQ 只描述管理端现象与排查步骤，不包含后端接口细节。

---

## 1. 我在后台“新增商品”成功了，但前台商城不显示

### 典型原因（按概率从高到低）

1) **商品只是“建档”，还没完成“可售配置（SKU/配置）”**

- 现象：商品列表能看到商品，但前台列表/搜索不到。
- 原因：很多前台展示逻辑只展示“有可售配置/有价格/有库存”的商品。

2) **库存为 0 或低于限制**

- 现象：商品有配置，但前台仍看不到，或进入详情显示不可购买。
- 原因：前台往往会过滤掉无库存商品，或 SKU 全部不可售。

3) **商品或配置状态为“下架”**

- 现象：后台能看到，但前台不展示。
- 原因：前台只展示“正常/上架”状态。

4) **还没被加入“上架商品 / 展示位（首页/新品/专区）”**（如果前台页面依赖运营位）

- 现象：前台首页/新品/专区不出现，但可能在“全量商品列表”里能看到。
- 原因：运营位通常是“精选展示”，需要单独配置。

### 你可以按这个顺序排查（建议照做）

#### 第一步：确认商品状态

1. 进入：`商品管理 → 商品管理`（商品列表）
2. 搜索到该商品
3. 查看“状态”列是不是 **正常**

**预期结果**：状态为正常；如果是下架，请在列表操作里把它改回可售状态（如果页面提供）。

#### 第二步：补齐商品“配置/SKU”（价格与规格）

1. 在商品列表点击该商品的 `详情` 或进入 `商品详情`
2. 打开 `配置/SKU`（或相关 Tab）
3. 至少新增 1 条配置：填写规格组合、销售价/原价、（如需要）配置图片

**预期结果**：商品至少有 1 个可用配置，并能在商品详情页看到。

#### 第三步：配置库存

1. 进入：`商品管理 → 库存管理`
2. 搜索该商品/配置（可用商品名或规格关键字）
3. 点击 `编辑`
4. 设置：
   - 库存数（建议先设置为 > 0）
   - 预警值（可选）

**预期结果**：保存后列表提示“库存配置已更新”，该 SKU 的可用库存 > 0。

#### 第四步：检查是否需要“商城管理”里上架/运营位配置

如果你希望它出现在首页/新品等精选区域：

1. 进入：`商城管理 → 上架商品管理`
2. 新建或找到对应“上架单元”
3. 绑定对应商品/配置，并保存
4. 再进入：
   - `商城管理 → 首页展示管理` 或
   - `商城管理 → 新品展示管理`
5. 把该上架单元加入展示位并保存

**预期结果**：保存后，前台首页/新品位出现该商品（可能存在缓存/延迟，刷新或等待一会儿）。

## 2. 商品在后台显示正常，但前台价格/规格不对

### 可能原因

- 配置（SKU）没有维护完整：例如原价/售价为空、规格字段填错顺序
- 多条配置存在重复规格组合，前台取默认配置时命中错误

### 解决建议

1. 进入商品详情 → 配置/SKU
2. 逐条检查：规格字段（config1/config2/config3）是否一致且无重复
3. 检查价格字段是否都已填写
4. 对不需要的配置设置为不可售或下架（如果页面支持）

**预期结果**：前台规格选择器与价格展示正确。

---

## 3. 上传图片后不显示 / 显示为破图

### 排查步骤

1. 先看后台页面里是否能预览（主图上传后应该立即出现本地预览）
2. 保存后刷新页面，确认保存后的图片 URL 是否存在
3. 如果 URL 以相对路径展示：检查 `lenovo-admin/.env` 的 `VITE_PUBLIC_LENOVO_IMAGE_PATH` 是否与部署静态资源目录一致

**预期结果**：图片在后台可回显、前台可访问。

---

## 4. 订单无法发货 / 点击提交没反应

### 排查步骤

1. 进入：`售货管理 → 订单管理`
2. 确认订单状态为 **待发货** 才会出现 `发货` 按钮
3. 进入发货页后：物流单号必填

**预期结果**：提交后提示“发货成功”，并回到订单列表，订单状态更新。

---

## 5. 看到“模拟数据/Mock 数据”标签或出现模拟列表

部分页面在接口获取失败时会回退到模拟数据（用于演示/开发体验）。

### 处理方式

1. 优先确认后端服务已启动且地址配置正确（`VITE_API_BASE_URL`）
2. 刷新页面

**预期结果**：不再使用模拟数据，列表显示真实数据。
