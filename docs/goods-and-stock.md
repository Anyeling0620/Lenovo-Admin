# 商品与库存使用手册

目标：把“商品建档 → 可售配置（SKU）→ 库存 → 上架/展示”串起来，避免“新增了但前台看不到/不能买”。

> 你可以先读一遍：[常见问题：新增商品但前台不显示](faq.md#1-我在后台新增商品成功了但前台商城不显示)

---

## 1. 商品建档（商品管理 → 商品管理 → 新建）

### 入口

- 菜单：`商品管理 → 商品管理`
- 按钮：`新增`/`新建商品`

### 表单字段（你需要填什么）

- 商品名称：必填
- 品牌：必选
- 分类：必选
- 副标题：可选
- 描述：可选
- 主图：建议上传（仅图片、< 5MB）
- 标签：可选（用于前台筛选或运营位）

### 提交后你会看到什么

- 弹出成功提示（如“商品录入成功”）
- 自动返回商品列表

> 注意：此时通常只是“建立商品档案”，并不代表前台一定可见。

---

## 2. 配置可售规格（SKU/配置）

### 为什么必须做

大多数前台会要求“至少存在 1 个可售配置（含价格）”，否则商品可能不展示或不可购买。

### 操作路径

1. 从商品列表点击该商品的 `详情`
2. 进入 `配置/SKU` 的 Tab 或相关区域
3. 新增配置并填写：
   - 规格字段（例如 config1/config2/config3）
   - 销售价/原价
   - 状态（可售/下架，取决于页面）

### 预期结果

- 商品详情页能看到至少 1 条配置
- 前台能读取到价格与规格组合

---

## 3. 维护库存（商品管理 → 库存管理）

### 入口

- 菜单：`商品管理 → 库存管理`

### 常见用法

- 搜索：商品名/规格关键字/库存ID/配置ID
- 状态筛选：
  - 预警：库存 ≤ 预警值
  - 冻结：冻结数 > 0

### 关键按钮与预期结果

- `详情`：打开弹窗，查看库存数/预警值/冻结数/更新时间
- `编辑`：打开弹窗，修改库存数与预警值
  - 保存后：提示“库存配置已更新”，表格该行立即更新
- `批量编辑`：先勾选多条，再批量“设置/增加/减少”库存
  - 保存后：所有勾选项按规则更新

> 建议：新商品联调时先把库存设置为一个较明显的正数（例如 100），便于确认前台展示逻辑。

---

## 4. 商品在前台的展示（是否需要“上架商品/展示位”）

你的前台如果是“运营位驱动”（首页/新品/专区只展示运营选中的内容），那你还需要配置：

- 菜单：`商城管理 → 上架商品管理`
- 菜单：`商城管理 → 首页展示管理` / `新品展示管理`

### 预期结果

- 上架单元创建/保存后：可被添加到展示位
- 展示位保存后：前台首页/新品区出现该商品

---

## 5. 最小验证清单（照着勾，能避免 90% 问题）

- [ ] 商品状态为“正常/可售”（不是下架）
- [ ] 至少 1 个配置（SKU）存在且有价格
- [ ] 该 SKU 库存 > 0
- [ ] 若前台依赖运营位：已加入上架商品 + 配置到首页/新品展示位
