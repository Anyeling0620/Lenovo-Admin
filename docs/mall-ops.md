## 1. 上架商品管理

### 入口

- 菜单：`商城管理 → 上架商品管理`

### 你能做什么

- 把“商品 + 可售配置（SKU）”组织成可被前台展示/售卖的上架单元
- 对上架单元设置一些展示属性（例如是否轮播、标签、排序、上下线时间等，具体以页面字段为准）

### 常见操作与预期结果

- `新建/新增`
  - 选择关联商品/配置并保存
  - **预期结果**：上架单元出现在列表中，后续可被首页/新品展示位引用

- `编辑`
  - 修改展示属性并保存
  - **预期结果**：前台对应展示发生变化（可能需要刷新或等待缓存过期）

- `启用/停用`（若页面提供）
  - **预期结果**：停用后不再在前台出现；启用后恢复展示

## 2. 首页展示管理

### 入口

- 菜单：`商城管理 → 首页展示管理`

### 你能做什么

- 配置首页的展示位（轮播/推荐位/模块等）
- 给展示位绑定“上架单元”
- 设置展示时间、排序与图片等

### 常见操作与预期结果

- `新增展示` / `添加`
  - 绑定上架单元并保存
  - **预期结果**：前台首页对应区域出现该内容

- `编辑`
  - 调整开始/结束时间、排序、图片
  - **预期结果**：前台展示顺序/图片/有效期更新

---

## 3. 新品展示管理

### 入口

- 菜单：`商城管理 → 新品展示管理`

### 你能做什么

- 配置新品模块中出现的上架单元

### 预期结果

- 保存后，前台新品区域展示更新（可能需要刷新或等待缓存）
